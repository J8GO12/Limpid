# Captures à faire pour la fiche CurseForge

Astuce : `/lpd` affiche d'un coup des lignes d'exemple dans le chat et une liste de butin remplie, figées jusqu'à ce que vous retapiez `/lpd`.

Résolution native, interface du jeu visible, sans autre addon de chat. Format PNG ou JPG.

1. **Vue d'ensemble** : en jeu, la fenêtre de chat transparente avec quelques lignes nettes
   (`+ objet`, `+ PX`, `+ réputation`, argent). C'est l'image principale.
2. **Avant / après** : la même scène avec le chat Blizzard (addon désactivé) puis avec Limpid.
3. **Liste de butin** : juste après avoir ramassé plusieurs objets, dont un avec la flèche verte
   et une ligne de pièces.
4. **Infobulle au survol** d'une ligne de la liste de butin.
5. **Déplacement** : `/limpid lock` et `/limpid loot` actifs, cadres dorés visibles.
6. **Options** : la fenêtre `/limpid`, onglet des filtres.
7. **Fenêtre détachée** (facultatif) : deux fenêtres de chat à l'écran.
